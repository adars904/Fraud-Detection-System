# Fraud Detection System

## Overview
This project aims to build an end-to-end fraud detection system using the IEEE-CIS Fraud Detection dataset. The project follows a complete machine learning pipeline from data preprocessing to model deployment.

---

## Dataset

- IEEE-CIS Fraud Detection Dataset
- Source: Kaggle

---

## Progress

### Completed

- Dataset loading
- Dataset merging
- Exploratory Data Analysis (EDA)
- Data cleaning
  - Categorical feature cleaning
  - Numerical feature cleaning
- Train-Test Split
- Missing value analysis
- Missing value handling strategy
- Initial preprocessing pipeline
- Feature Engineering

### Engineered Features

- Log transformed Transaction Amount
- Transaction Amount Decimal Feature
- User ID (uid)
- Average Transaction Amount per User
- Standard Deviation of Transaction Amount per User
- Transaction Amount to User Mean Ratio
- Purchaser Email Provider
- Recipient Email Provider
- Email Match Feature
